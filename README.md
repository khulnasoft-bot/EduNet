# EduNet Agent Scaffold

This package contains the autonomous implementation contract, skills, prompts,
domain TODOs and 100 production completion gates.

## Start
1. Read `agent/MASTER_AGENT.md`
2. Read `docs/source-specification.md`
3. Read `prompts/MASTER_IMPLEMENTATION.md`
4. Inspect the target repository
5. Execute the implementation sequence without asking questions
6. Track completion in `todo/`
7. Do not mark a gate complete until the implementation and tests support it.

The scaffold is intentionally repository-adaptive: agents must preserve useful
existing code and conventions rather than blindly recreating the proposed tree.
